# rulof.dev

Monorepo for [rulof.dev](https://rulof.dev): static site plus an optional SSH TUI.

| Directory | What |
|-----------|------|
| [`web/`](web/) | Angular app → Cloudflare Pages |
| [`tui/`](tui/) | Rust SSH server + ratatui UI (e.g. `tui.rulof.dev`) |

See each folder’s README for how to run and build it.
